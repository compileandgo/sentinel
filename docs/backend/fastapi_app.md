# FastAPI Web Layer & SSE Streaming

This document details the web application layer located in `src/web/app.py`.

---

## Key Libraries Used

* **`fastapi.FastAPI`**: Main web application framework.
* **`starlette.responses.StreamingResponse`**: Handles Server-Sent Events (SSE) data streaming over HTTP.
* **`pyjwt`**: Decodes and verifies Supabase JWT Bearer tokens (`Authorization: Bearer <token>`).
* **`concurrent.futures.ThreadPoolExecutor`**: Offloads synchronous LangGraph graph execution off the main asyncio event loop.

---

## API Endpoints

### 1. Research Execution
* **`POST /api/research`**: Starts a deep research run.
 * **Payload**: `{"topic": "...", "max_iterations": 1, "max_subagents": 3}`
 * **Logic**:
 1. Validates query length ($\ge 10$ chars) and rate limit (10 runs / 24h).
 2. Writes initial user query & chat session to Supabase database.
 3. Spawns `run_agent_in_thread()` inside `ThreadPoolExecutor`.
 4. Returns `{"run_id": "...", "chat_id": "..."}` immediately.

* **`GET /api/stream/{run_id}`**: Server-Sent Events (SSE) streaming endpoint.
 * **Query Params**: `?token=<jwt_access_token>`
 * **Logic**: Subscribes to Redis channel `sse:{run_id}` and yields SSE formatted event frames:
 ```http
 data: {"type": "log", "data": {"message": "[LeadResearcher] Formulating plan...", "timestamp": "02:15:00"}}
 
 data: {"type": "plan_ready", "data": {"plan_path": "...", "message": "Waiting for approval"}}
 ```

* **`POST /api/research/resume/{run_id}`**: User clicks 'Proceed' to approve research plan.
 * **Logic**: Sets `threading.Event()` and updates Redis key `run:{run_id}:approved` $\rightarrow$ background thread resumes execution.

* **`POST /api/research/cancel/{run_id}`**: User clicks 'Cancel'.
 * **Logic**: Stores `run_id` in Redis `cancellations` set $\rightarrow$ execution loop terminates gracefully.

---

### 2. Q&A Interactive Chat
* **`POST /api/chat`**: Standard JSON Q&A response endpoint.
 * **Logic**: Enforces rate limit (30 msgs / 24h) $\rightarrow$ checks semantic vector cache $\rightarrow$ if miss, runs Hybrid Search + LLM $\rightarrow$ returns JSON answer.

* **`POST /api/chat/stream`**: SSE Streaming Q&A response endpoint.
 * **Logic**: Streams LLM token chunks live to the user as they are generated by Groq or Gemini.

## Thread Isolation & Stdout Hijacking

Because LangGraph nodes write status messages using standard `print()` calls, Sentinel uses custom stdout redirection (`StdoutRedirector` in `src/web/app.py`) inside `run_agent_in_thread()`:

```python
class StdoutRedirector:
 def __init__(self, callback):
 self.callback = callback
 def write(self, buf):
 for line in buf.rstrip().splitlines():
 if line.strip():
 self.callback(line.strip())
```

When `print()` is called inside an agent thread:
1. `StdoutRedirector` captures the string line.
2. Formats a JSON event object (`{"type": "log", "data": {...}}`).
3. Calls `asyncio.run_coroutine_threadsafe(publish_run_event(run_id, evt), loop)` to push it onto the Redis Pub/Sub channel.
